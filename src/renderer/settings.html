NACEF (fiscalisation)

Mode NACEF

Activer le mode NACEF Au démarrage : ajoute les routes réseau vers les serveurs fiscaux (élévation demandée une seule fois) et lance le proxy CORS local vers le boîtier S-MDF.

Proxy CORS local

Cible du proxy Boîtier S-MDF local (http://localhost:10006), ou pour un poste relayé, le proxy d'un autre poste du réseau (ex. http://192.168.1.50:10007). L'URL appelée par le site reste toujours 127.0.0.1 — seule la cible change.
Redémarre le proxy local immédiatement avec la nouvelle cible.

Routes fiscales

Passerelle (next hop) Adresse locale par laquelle joindre les serveurs fiscaux (ex. 192.168.1.253)
Serveurs fiscaux (destinations) IP publiques routées via la passerelle (masque /32). Une IP par ligne.
Enregistrer applique les nouvelles routes (élévation demandée si le mode est activé et qu'une route manque). Modifier la passerelle ne supprime pas les anciennes routes.
